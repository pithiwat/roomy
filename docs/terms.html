เกี่ยวกับ Roomy

Roomy เป็นโปรแกรมดูแลเครื่องและจัดการพื้นที่ดิสก์สำหรับ Windows 10 และ 11 พัฒนาและเผยแพร่โดยนักพัฒนาอิสระภายใต้ชื่อ Roomy ("เรา") การดาวน์โหลด ติดตั้ง หรือใช้งาน Roomy ถือว่าคุณยอมรับข้อกำหนดนี้

การสั่งซื้อ

Roomy Pro ขายผ่าน Microsoft Store โดย Microsoft เป็นผู้รับชำระเงิน คิดภาษีตามที่กฎหมายกำหนด ดูแลการสมัครสมาชิก และการคืนเงิน ตามข้อกำหนดการขายของ Microsoft Store ราคาแสดงใน Microsoft Store เป็นสกุลเงินของคุณ

เวอร์ชันฟรี ทดลองใช้ และ Pro

เวอร์ชันฟรีใช้ได้ฟรี ทดลองฟีเจอร์ Pro ได้ฟรี 7 วัน หนึ่งครั้งต่อเครื่อง ไม่ต้องใส่บัตร Roomy Pro ขายแบบสมาชิกรายเดือนหรือรายปี ซึ่งต่ออายุอัตโนมัติทุกรอบจนกว่าคุณจะยกเลิก หรือแบบตลอดชีพ (จ่ายครั้งเดียว ไม่หมดอายุ) ยกเลิกสมาชิกได้ทุกเมื่อในบัญชี Microsoft (account.microsoft.com/services) จากนั้น Pro ยังใช้ได้จนครบรอบที่จ่ายไว้ และจะไม่มีการตัดเงินอีก

สิทธิ์การใช้งาน

Roomy Pro เป็นของบัญชี Microsoft ที่ซื้อ ใช้ได้บนเครื่องที่ลงชื่อเข้า Microsoft Store ด้วยบัญชีนั้น ตามจำนวนเครื่องที่ Microsoft Store กำหนด ห้ามแชร์ ขายต่อ หรือพยายามหลบเลี่ยงการตรวจสิทธิ์ ส่วน license key ที่เราออกให้โดยตรงเป็นของบุคคลเดียวและใช้กับคอมพิวเตอร์ของตัวเอง

ไฟล์ของคุณ

Roomy ลบเฉพาะสิ่งที่คุณยืนยัน และเฉพาะแคชหรือไฟล์ชั่วคราวที่ Windows และโปรแกรมสร้างใหม่ได้ เว้นแต่คุณเลือกย้ายไฟล์ลงถังขยะเอง การย้ายโฟลเดอร์ย้อนกลับได้ และโปรแกรมที่พักไว้ปลุกกลับได้ คุณรับผิดชอบการสำรองข้อมูลของตัวเอง ควรสำรองข้อมูลสำคัญไว้เสมอ

ไม่มีการรับประกัน

Roomy ให้บริการ "ตามสภาพ" โดยไม่มีการรับประกันใด ๆ เท่าที่กฎหมายอนุญาต เราไม่รับผิดชอบความเสียหายทางอ้อม ข้อมูลสูญหาย หรือการสูญเสียรายได้ ความรับผิดรวมของเราจำกัดไม่เกินจำนวนเงินที่คุณจ่ายค่า Roomy Pro ใน 12 เดือนก่อนการเรียกร้อง
